# 🌤️ Skies — Weather App

A clean, responsive weather app built with **HTML, CSS, and JavaScript**. No API key required — uses the free [Open-Meteo API](https://open-meteo.com/).

## ✨ Features

- 🔍 Search weather by **city name**
- 📍 **Detect current location** with one click
- 🌡️ Current temperature, feels-like, and weather condition
- 💧 Humidity, 💨 Wind speed, ☀️ UV Index, 👁️ Visibility stats
- ⏱️ **12-hour hourly forecast** (scrollable)
- 📅 **7-day daily forecast** with high/low temps
- 🎨 Card background **changes color** based on weather
- ⚡ No API key needed — completely free
